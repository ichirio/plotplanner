# CDISC Analysis Results Standard (ARS) v1.0: JSON Schema

`ars_ldm.json` is the JSON Schema of the CDISC ARS v1.0 logical data model,
copied unchanged from CDISC's repository:

- source: https://github.com/cdisc-org/analysis-results-standard,
  tag `v1.0.0`, file `model/ars_ldm.json`
- licence: MIT (the repository's `LICENSE`), reproduced below

`tfl_check_ars()` checks a reporting event against it (with the jsonvalidate
package).
