# plotplanner

Generate **ggplot2 / extension-package code** for clinical (and some non-clinical) figures from an **Excel spec**.

- Pick a plot type (swimmer, KM, forest, waterfall, sankey, ...)
- Choose variables and codelist values **from the ADaM datasets you supply** (drop-down lists in the spec)
- Choose legend / theme / palette from a small set of presets
- Get a runnable skeleton script — finish the details by hand

Status: **design phase**. Design discussion and sample-code contributions:
see [Discussions](https://github.com/ichirio/plotplanner/discussions).
